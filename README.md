# 🌐 防災情報ポータル - ソナエール・ライブ (v5.0.25) ※試験版

気象庁発表の地震・津波データをリアルタイムに取得・可視化する、単一ファイル構成の防災情報Webアプリケーションです。常時表示の防災モニターにも対応しています。

---

## 🌐 公開サイト（今すぐブラウザで使う）

👉 [ソナエール・ライブ Web版はこちら](https://sites.google.com/view/sonael-live-net/)

## 📌 主な機能

- **📡 WebSocketリアルタイム配信（v5.0〜）**
  - 「P2P地震情報 API v2」のWebSocket API（`wss://api.p2pquake.net/v2/ws`）へ常時接続し、地震・津波・緊急地震速報の電文を受信した瞬間（通常1秒以内）に画面へ反映。
  - **反映までの時間：** アプリが即時に行えるのは「P2P地震情報が再配信してから画面反映まで」（通常1秒以内）です。地震発生から気象庁の発表までは、緊急地震速報（警報）で数秒〜十数秒、震度速報で約1分、震源に関する情報・各地の震度に関する情報で約1〜5分が目安です（気象庁資料に基づく）。
  - 切断時は指数バックオフ（1s→2s→4s…最大30s＋ジッター）で自動再接続。readyState監視のwatchdog、タブ復帰時の自動再接続、接続（再接続）のたびにHTTP `/v2/history` で最新状態を即時補完を搭載。
  - **自動フォールバック（v5.0.1〜）：** WebSocketが接続できない環境では、5回連続失敗でHTTPポーリング（15秒）へ自動切替。ポーリング中も5分おきにWS復旧を内部プローブし、復旧したらWS監視へ自動復帰します。
  - **フェイルセーフ照合（v5.0.1〜／v5.0.9で60秒おきへ短縮）：** WS監視中も60秒おきにHTTPで静かに最新状態と照合し、電文の取りこぼしを防止します（「最終受信」時刻が定期的に更新され、監視が生きていることを確認できます）。
  - HTTPポーリング（15秒／30秒／60秒）へワンタップで手動切替も可能。従来の「1秒間隔フェッチ」方式を廃止し、サーバー負荷とレート制限（60req/min）の問題を解消。

- **🚨 緊急地震速報（予報・code 554／警報・code 556）の実報対応（v5.0〜／v5.0.4〜裏側処理／v5.0.5〜詳細画面に記載）**
  - 緊急地震速報（予報・警報）は、常時表示モニターとしての視認性・静穏性を優先し、**画面パネル・専用アラート音・自動読上げは発報しません**（v5.0.4〜）。
  - 受信したEEW電文はモニターバーのログへ静かに記録され、**551（震度速報）と発生時刻±90秒で自動相関**した上で、詳細画面の「緊急地震速報」欄に、実際に発表された内容どおりに記載します（v5.0.5〜）。
    - 警報（code 556）を受信 →「【警報】（受信済・第N報）」
    - 警報が取消（cancelled）された電文のみ →「【警報】（発表後取消）」
    - 予報（code 554・EEW検知）を受信 →「【予報】（受信済）」
    - 同一地震に未取消の556と554が両方ある場合は警報（受信済）を、取消556のみなら「発表後取消」を優先記載します。
  - EEW受信後に観測震度が震度3以下だった場合（空振り）は、詳細画面の「緊急地震速報」欄に「緊急地震速報【予報】／【警報】」とだけ記載します（v5.0.6〜。付記や注記バナーは表示しません）。第N報の続報更新・取消（cancelled）の検知、554の受信補完（起動時・再接続時にHTTP `/v2/history` から最新554/556を取得）もすべて裏側処理で行います。
  - **受信した予報の引き継ぎ（v5.0.25〜）：** 予報（code 554）を受信すると、その後に発表される地震情報（code 551）の「緊急地震速報」欄へ「緊急地震速報【予報】」を引き継ぎます（発生時刻±90秒・震央地名で照合／震度2でも表示）。受信した予報は localStorage に保存（6時間・最大60件）し、再読み込みや地震情報の遅延があっても失われません。
  - **気象庁公表一覧との照合（v5.0.23〜）と自動更新（v5.0.24〜）：** 実電文を取りこぼした地震でも、気象庁が実際に発表した区分（【警報】／【予報】）を表示します。同梱427件（警報339・予報88）に加え、気象庁の公表ページ（予報: `fc_hist/index.html`／警報: `pub_hist/index.html`／いずれも `Access-Control-Allow-Origin: *`）を起動時・10分ごと・地震検知の約5分後に取得して更新します。取得に失敗した場合は同梱分で動作します。公表一覧で判定した場合は「（受信済）」等を付記しません。
  - **優先順位：** ① 警報（556）→「【警報】（受信済・第N報）」／② 警報取消 →「【警報】（発表後取消）」／③ 予報（554）→「【予報】（受信済）」／④ 気象庁公表一覧 →「【警報】／【予報】」／⑤ どれも無い →「発表なし（基準以下）」。

- **🌊 津波モニター（code 552・v5.0〜）**
  - 大津波警報／津波警報／津波注意報の区分、対象沿岸名、予想高さ（巨大／高い／１０ｍ超など）、第1波到達予想（arrivalTime／「ただちに津波来襲と予測」などのcondition）、即時避難（immediate）を専用パネルにて表示。解除（cancelled）にも対応します。

- **⏱️ 日本標準時（JST）自動補正エンジン**
  - デバイス（PC・スマホ）の内蔵時計が狂っていても、外部の高精度WebNTPサーバーと1分おきに自動同期して正確な日本時間をキープ。APIの日時文字列は常にJST（+09:00）として厳密に解釈するため、閲覧端末のタイムゾーンに依存せず時系列が正しく並びます。

- **🗂️ 余震・前震をアーカイブ項目として収録（v5.0.21〜パネル／v5.0.22〜アーカイブ項目）**
  - 余震・前震を本震とは別のアーカイブ項目として収録しています（各地の観測震度＝震度7〜1・市町村区別も1件ずつ保持）。
  - 「過去の大地震」タブで本震カードの下に「└ 余震・前震（この本震の系列）」を折りたたみ表示。前震は青・余震は黄のバッジで区別し、一覧カードには「余震N」「前震N」「余震なし」バッジを出します。
  - 各項目を開くと震度一覧の上に<b>余震・前震（震度5弱以上）</b>パネルを表示し、発生時刻・最大震度・規模・震源地・備考（最大余震など）を掲載します。令和8年熊本地震＝余震5回・前震なし／岩手県沖＝余震1回（6/28 M6.1 震度5弱）・前震なし／トカラ列島近海＝前震3回＋余震4回（最大震度5強）。山梨県東部・富士五湖／青森県東方沖／日向灘／豊後水道は「震度5弱以上の余震・前震なし」を明示します。
  - 余震・前震の各項目にも、震源位置（緯度/経度）・緊急地震速報・津波情報を収録しています（例：熊本の最大余震 M6.1 は北緯32.4°／東経130.5°・緊急地震速報【警報】・津波注意報発表）。緊急地震速報欄は気象庁の発表区分どおりに【警報】／【予報】を表示します。
  - 新規13件で警報が発表されたのは 2026/07/28 17:08・07/29 22:19・2025/07/02 15:26・07/06 14:07 の4件で、残り9件は予報のみ（警報は未発表）です。2007年10月の警報運用開始前の地震は「制度開始前（2007年以前）」と表示します。
  - 余震・前震の項目を開くと「この地震は『◯◯』の余震です」と表示し、「← 本震の詳細へ戻る」で行き来できます。

- **🏛️ 過去の大地震アーカイブ（全49件＝本震17件＋余震・前震32件）**
  - 東日本大震災、阪神・淡路大震災、熊本地震、能登半島地震などの観測データを市区町村単位で収録。オフラインでも振り返り可能です。
  - 2024年以降に震度6弱以上を観測した地震7件（令和8年熊本地震・山梨県東部・富士五湖・岩手県沖・青森県東方沖・トカラ列島近海・日向灘・豊後水道）については、**震度7〜震度1の全観測地点（7件合計 4,030 地点）を市町村・行政区別に収録**しました（v5.0.20）。
  - tenki.jp 独自の短縮表記は正式名称へ統一（例: 熊本南区 → 熊本市南区、青森南部町 → 南部町、岩手洋野町 → 洋野町、静岡葵区 → 静岡市葵区）。
  - 市町村・区別一覧の右下に「出典: 気象庁ホームページ／tenki.jp 地震情報」を表示します。

- **🔄 電文合体（マージ）引き継ぎロジック（v5.0.7〜最新電文優先）**
  - 第1報「震度速報」の震度データを、直後に届く第2報「震源に関する情報」へ自動引き継ぎ。震源決定直後に震度が「不明」に戻る現象を防止。
  - 同一地震の電文グループは「発報時刻（issue.time）の新しい順」に並べて最新の電文を正しく選択します（v5.0.7〜）。震度速報→震源に関する情報→各地の震度に関する情報の順で表示が更新されます。
  - ライブ地震のエントリIDは地震（発生時刻）単位で固定されるため、電文が届くたびに選択中の詳細画面も最新の内容へ自動更新されます（v5.0.7〜）。

- **🔊 音声読み上げ（アクセシビリティ）**
  - Web Speech API を活用し、画面を見られない緊急時でも合成音声で地震情報を確認可能。v5.0では、アラート受信時の**自動音声読上げ**と**専用アラート音（Web Audio）**を搭載し、v5.0.4以降はEEW（予報・警報）を自動読上げ・専用音の対象外としました。v5.0.8以降、アラート音（効果音）は**津波警報・大津波警報のチャイムのみ**となり、津波注意報・解除・訓練地震などのinfoチャイムは廃止しました（自動読上げも津波警報・大津波警報の受信時のみです）。
  - 🔊「音声読上」ボタンの読み上げ文は、v5.0.11で**気象庁の発表体**（「地震情報。午前／午後〇時〇分頃、最大震度〇を観測する地震がありました。…」）へ全面刷新。震度3以上の地震では、震度の高い地域から順に「この地震で最大震度〇を、〇〇で観測しました。また、最大震度〇を、〇〇で観測しています。」（震度3まで）を読み上げます。地域名は気象庁の震度観測地域名（地震情報／細分区域・全国188区域。例：熊本県天草・芦北、東京都２３区、石川県能登）で読み上げます（読み上げは難読語だけ仮名に変換：天草→あまくさ、中越→ちゅうえつ、能登→のと など。語の区切りが崩れないよう漢字はそのまま残します。画面表示は漢字のまま）。市区町村→細分区域の対応表（約5,150件・気象庁「予報区等GISデータ」準拠）を内蔵し、震度速報の地域別震度と突き合わせて地域ごとの最大震度を採用します（過去アーカイブも同じ表で写像）。震度2以下では地域名を読みません。津波が発表中の場合は「〇〇を発表中です。」と読みます。EEWは従来どおり読み上げません。

- **🖥️ 常時表示モニター向けコントロール（v5.0〜）**
  - モニターバーに、WS接続状態／P2P参加ピア数（code 555）／ユーザー体感報告（code 561・9611／信頼度付き）／津波発表状況を常時表示。
  - アラート音ON/OFF・自動読上げON/OFF・画面スリープ防止（Wake Lock API）・フルスクリーン切替をワンタップ操作（設定は端末に保存されます）。
  - **訓練モード（🧪）**：実報と紛れないよう「訓練」バッジ付きで、EEW発報／EEW取消／EEW予報（v5.0.5〜）／津波警報／デモ地震を任意のタイミングで試射できます。音の確認は訓練の「津波警報」ボタン（チャイム＋読上げ）で行えます。

- **📝 気象庁フリーコメント表示（v5.0〜）**
  - 551電文の `comments.freeFormComment`（気象庁のコメント）を地震詳細パネルに併記します。

- **📱 スマホ表示の最適化（v5.0.2〜）**
  - モニターバーが画面幅で自動折り返し、iOSの入力自動ズーム防止、safe-area（ノッチ）対応、ボトムナビのアクティブ表示など、モバイル専用の使いやすさを強化。

- **📱 レスポンシブ＆ダークモードUI**
  - PCでは詳細・リストの2カラム、スマホではボトムナビゲーションによる快適な操作性を実現。Tailwind CSSは**インライン化済み（CDN不要）**のため、回線が不安定でも表示が崩れません。

## 🛠️ 使用技術

- **フロントエンド**: HTML5 / JavaScript (Vanilla JS) / Tailwind CSS（コンパイル済みCSSをインライン同梱）
- **配信形式**: 単一ファイルSPA（ビルド不要、ブラウザで開くだけで即起動）
- **利用API**:
  - [P2P地震情報 JSON API v2](https://www.p2pquake.net/)（気象庁電文）
    - WebSocket: `wss://api.p2pquake.net/v2/ws`（リアルタイム配信）
    - REST: `https://api.p2pquake.net/v2/history`（起動時・再接続時の欠損補完）
    - 電文コード: 551（地震）／552（津波警報・注意報）／554（EEW検知）／555（P2Pピア数）／556（EEW警報）／561・9611（ユーザー体感報告）
  - [WebNTP API](https://webntp.shogo82148.com/) / TimeAPI（日本標準時同期）
  - Web Speech API（ブラウザ標準 音声合成）
  - Web Audio API（アラート音）／Wake Lock API（画面常時ON）／Fullscreen API（全画面表示）

## 🚀 使い方

1. `sonaeru_live_v5.html` をダウンロードします。
2. お好みのブラウザ（Google Chrome, Safari, Edgeなど）でファイルを開くだけで動作します。
3. 画面上部のセレクトは「**WS自動（推奨）**」のままでOK。地震や津波が発生すると、気象庁が発表した電文をもとに自動で表示されます（発表からの反映は通常1秒以内）。平常時は画面が変化しませんが、これはWSが「地震発生時のみ」に電文を配信する仕様のためです（モニターバーにWS接続状態と最終受信時刻を常時表示しているので、監視の生死はそこで確認できます）。60秒おきのフェイルセーフ照合も内蔵しています。
   - 万が一環境がWSを遮断する場合は自動で「HTTP 監視中（15秒ポーリング）」に切り替わり、5分おきにWS復旧を自動確認します。
4. 常時表示モニターとして使う場合は、**⛶全画面**と**🔆常時ON**を有効化してください。
5. **🧪訓練**をONにすると、EEW／EEW取消／EEW予報／津波／地震のテスト電文を注入できます（EEWは画面には出ず、裏側のログ記録と551との相関処理のみ行い、詳細画面の「緊急地震速報」欄に受信済表示を反映します。実際の地震・津波情報ではありません。※訓練モードをOFFにすると消えます）。

## ⚖️ 免責事項

- 本サービスは個人開発による非公式の防災情報ポータルです。
- 緊急時や避難の判断には、自治体の防災無線、気象庁の公式発表、NHK等の公的報道機関の情報を最優先してください。
- 訓練モードで発報される電文はすべてテストデータであり、実際の地震・津波情報とは無関係です。
