# 🌐 防災情報ポータル - ソナエール・ライブ (v6.2) ※試験版

気象庁発表の地震・津波データをリアルタイムに取得・可視化する、単一ファイル構成の防災情報Webアプリケーションです。常時表示の防災モニターにも対応しています。

## 📌 主な機能

- **📡 リアルタイム受信（3経路）**
  - **気象庁XML電文フィードを20秒ごとに直接確認**します（地震情報 VXSE51/52/53・緊急地震速報 VXSE43/45）。気象庁が発表した一次情報をそのまま受けるため、**発表から数秒**で反映されます。
  - **緊急地震速報（予報・警報）は Wolfx API から直接受信**します（`wss://ws-api.wolfx.jp/jma_eew`、切断時は `api.wolfx.jp/jma_eew.json` を2秒間隔でポーリング）。予報・警報・取消・最終報・訓練（除外）をJSON1本で扱います。
  - 「P2P地震情報 API v2」のWebSocket（`wss://api.p2pquake.net/v2/ws`）へ常時接続し、地震・津波の電文を受信した瞬間（実測1.5秒）に画面へ反映します。ただし**P2P地震情報は有志のリレー**のため、地震情報が数十秒〜数分遅れることがあります。そのため気象庁XMLを主経路とし、P2Pは補完に使います。
  - アプリが即時に行えるのは「P2P地震情報が再配信してから画面反映まで」です。地震発生から気象庁の発表までは、緊急地震速報（警報）で数秒〜十数秒、震度速報で約1分、各地の震度に関する情報で約1〜5分が目安です。
  - 切断時は指数バックオフ（1s→2s→4s…最大30s）で自動再接続し、接続のたびに HTTP `/v2/history` で最新状態を補完します。

- **🔁 通信の冗長化**
  - WebSocketが使えない環境では、5回連続失敗で HTTP ポーリング（15秒／30秒／60秒・手動切替可）へ自動で切り替えます。ポーリング中も5分おきにWS復旧を試し、復旧すると自動で戻ります。
  - WS監視中も60秒おきにHTTPで最新状態と静かに照合し、電文の取りこぼしを防ぎます。

- **🚨 緊急地震速報（予報・警報）**
  - 気象庁が予報・警報を発表すると、**詳細画面の上部に帯（お知らせ）**を出します（例：「🚨 緊急地震速報（警報）が発表されました：日向灘」＋発表時刻・M・最大震度）。発表から**30分で自動的に消え**、✕ で閉じることもできます（次の発表でまた出ます）。**地震情報（code 551）が届く前**は「下の見出しは別の地震のことがあります」と注記します。
  - モニターバーの **EEW バッジに震源を併記**します（例：「EEW 予報 日向灘」「EEW 警報 熊本県天草・芦北地方」）。気象庁の発表一覧を取得した時点でバッジ・帯へ反映するため、電文（554/556）を取りこぼしていても発表の事実は表示されます。
  - **画面パネル・専用アラート音・自動読上げは行いません**（津波警報時の音声のみ従来どおり）。受信した電文はログに記録し、地震情報の「緊急地震速報」欄へ反映します。
  - 詳細画面には実際に発表された内容だけを表示します。
    - 警報（code 556）を受信 →「【警報】（受信済・第N報）」
    - 警報の取消のみ →「【警報】（発表後取消）」
    - 予報（code 554）を受信 →「【予報】（受信済）」
    - 空振り（震度3以下）の場合は「緊急地震速報【警報】／【予報】」とだけ表示
  - 予報を受信すると、その後に発表される地震情報へ「緊急地震速報【予報】」を引き継ぎます（震度2でも表示）。受信内容は端末に保存（6時間・最大60件）するため、再読み込みや地震情報の遅延があっても失われません。
  - **発表の検知は3経路**：① **Wolfx API**（気象庁の即時ミラー。予報・警報・取消・最終報）② **気象庁XML電文**（VXSE43＝警報／VXSE45＝予報。フィードに載ればこちらを優先）③ P2P地震情報の電文（556＝警報、554＝検知）と気象庁の発表一覧（**60秒ごと**）。
  - ⚠️ **P2P地震情報は予報の本体電文（code 553）を配信していません**（API仕様: 554＝検知のみ・震源なし、556＝警報のみ）。予報の震源・最大震度は気象庁XMLから取得します。
  - 電文を取りこぼした場合に備え、気象庁の発表一覧（警報・予報）と照合します。同梱427件に加え、起動時・**60秒ごと**・地震検知の約60秒後に一覧を取得して更新します（取得できない場合は同梱分で動作）。気象庁の一覧には10分のキャッシュが付くため、取得URLに時刻を付けて常に最新を読みます。
  - 表示の優先順位：① 警報 → ② 警報取消 → ③ 予報 → ④ 気象庁の発表一覧 → ⑤ どれも無ければ「発表なし」。観測されたM・震度からの推測は行いません（予報は推定Mで発表されるため、確定値からは判定できないためです）。

- **🌊 津波モニター（code 552）**
  - 大津波警報／津波警報／津波注意報の区分、対象沿岸名、予想高さ（巨大／高い／10m超など）、第1波到達予想、即時避難を専用パネルに表示します。解除にも対応します。

- **⏱️ 日本標準時（JST）自動補正**
  - 端末の内蔵時計が狂っていても、外部のNTPサーバーと1分おきに同期して正確な日本時間を保ちます。APIの日時は常にJST（+09:00）として解釈するため、端末のタイムゾーンに依存せず時系列が正しく並びます。

- **🗂️ 余震・前震の系列表示**
  - 余震・前震を本震とは別のアーカイブ項目として収録し、本震カードの下に「└ 余震・前震（この本震の系列）」として折りたたみ表示します。前震は青・余震は黄のバッジで区別し、一覧カードには「余震N」「前震N」「余震なし」バッジを出します。
  - 各項目を開くと、震度一覧の上に「余震・前震（震度5弱以上）」パネルを表示します。令和8年熊本地震＝余震5回・前震なし／岩手県沖＝余震1回（M6.1 震度5弱）・前震なし／トカラ列島近海＝前震3回＋余震4回（最大震度5強）など。震度5弱以上の余震・前震が無い場合はその旨を明示します。
  - 各項目にも震源位置（緯度/経度）・緊急地震速報・津波情報を収録しています。項目を開くと「この地震は『◯◯』の余震です」と表示し、本震の詳細へ戻れます。

- **🏛️ 過去の大地震アーカイブ（全49件＝本震17件＋余震・前震32件）**
  - 東日本大震災、阪神・淡路大震災、熊本地震、能登半島地震などの観測データを市区町村単位で収録しています。オフラインでも振り返り可能です。
  - 地点データは**気象庁 震度データベース**の全観測点から収録しています。49件合計で**延べ22,702地点・市区町村1,842件**。震度7〜震度1のすべての階級を、市町村・行政区別に掲載します。
  - 主な内訳（地点数）：東日本大震災 1,458／令和6年能登半島地震 1,339／福島県沖2022 1,177／福島県沖2021 1,135／東北余震 1,074・1,007ほか／新潟県中越地震・熊本地震などの主要地震も収録。
  - 詳細画面の「各地の観測震度 (市町村・区別一覧)」は、**震度｜都道府県｜観測市町村・区 (五十音順)** の3列表で表示します。震度の欄は色付きのセルで、震度が変わるごとに縦に結合します。市町村名は全角スペース区切りで折り返します。
  - 市区町村名は気象庁の市町村コード（観測点マスタ）から引くため表記が統一されています。区は「中央区」「南区」のように区名で表示し、「熊本西区」のような観測点名由来の短縮表記は使いません。
  - 平成の大合併で消滅した旧町村は現在の市町村に統合しています（例：川口町・山古志村・小国町・越路町・栃尾市 → 長岡市／堀之内町・広神村・守門村 → 魚沼市／前原市・志摩町 → 糸島市）。
  - 同じ市区町村は**最も高い震度の欄にだけ**掲載します。一覧の右下に出典を表示します。

- **🔄 電文の引き継ぎ**
  - 第1報「震度速報」の震度データを、直後に届く第2報「震源に関する情報」へ自動で引き継ぎます。震源決定直後に震度が「不明」に戻る現象を防ぎます。
  - 同一地震の電文は発報時刻（issue.time）の新しい順に並べ、最新の電文を採用します。地震のIDは発生時刻単位で固定されるため、電文が届くたびに選択中の詳細画面も最新の内容へ更新されます。

- **🔊 音声読み上げ**
  - Web Speech API により、画面を見られない緊急時でも合成音声で内容を確認できます（「音声読上」ボタンで読み上げ）。
  - 読み上げ文は気象庁の発表体（「地震情報。午前／午後〇時〇分頃、最大震度〇を観測する地震がありました。…」）です。震度3以上の地震では、震度の高い地域から順に最大震度と地域名を読み上げます。
  - **語尾の使い分け**：「観測しました」は**その地震の最大震度を言うときだけ**、「観測しています」は**震度3のときだけ**使います。それ以外の震度は「震度〇を、〇〇。」と簡潔に言います。「また」は最大震度の**次**の震度のときだけ付けます。
  - 読み上げ例：`この地震で最大震度5強を、宮城県中部で観測しました。また、震度4を、岩手県沿岸南部。震度3を、福島県浜通りで観測しています。`
  - 地域名は気象庁の震度観測地域名（細分区域・全国188区域）で読み上げます。市区町村→細分区域の対応表（約5,150件）を内蔵しています。震度2以下では地域名を読みません。
  - 自動読上げ・アラート音の対象は**津波警報・大津波警報のみ**です（EEWは音・画面・読上げのいずれも行いません）。

- **🖥️ 常時表示モニター向けの操作**
  - モニターバーに、WS接続状態／P2P参加ピア数／ユーザー体感報告（信頼度付き）／津波発表状況／**緊急地震速報の発表状況（EEWバッジ）**を常時表示します。
  - **EEWバッジ**：「EEW なし／予報／警報／取消」に**震源を併記**します（例：「EEW 予報 日向灘」「EEW 警報 熊本県天草・芦北地方」）。警報時は赤色で、最大震度が分かれば「警報 最大震度6弱」も併記し、マウスを乗せると震源・マグニチュード・報数・発表時刻が出ます。発表から30分が過ぎた速報は自動で「なし」に戻します。
  - **画面上部の帯**：予報・警報の発表があると、詳細画面の上に帯で知らせます（×で閉じられます）。
  - **ログ欄**：気象庁へのアクセス結果、緊急地震速報（予報・警報・取消）の発表、津波の発表などを時刻つきで記録します。PC・スマホのどちらでも表示され、長い文は折り返して全文を表示します（省略記号で切りません）。
  - **スマホ版の収納**：画面幅640px未満では、音・読上・常時ON・全画面・訓練のスイッチをヘッダー右の **☰** に収納します。☰ を押すとモニターバーの下に1行で展開します。ONのスイッチがあると ☰ に緑の数字バッジが出ます。PC・タブレットは従来どおり常時表示です。
  - 音声読上げ・画面スリープ防止（Wake Lock）・フルスクリーン切替をワンタップで操作できます（設定は端末に保存）。
  - **訓練モード（🧪）**：実報と紛れないよう「訓練」バッジ付きで、EEW／EEW取消／EEW予報／津波警報／デモ地震を任意に試射できます。

- **📝 気象庁フリーコメント表示**
  - 地震電文の `comments.freeFormComment`（気象庁のコメント）を詳細パネルに併記します。

- **📱 レスポンシブ＆ダークモードUI**
  - PCでは詳細・リストの2カラム、スマホではボトムナビゲーションで操作できます。モニターバーの自動折り返し、iOSの入力自動ズーム防止、safe-area（ノッチ）対応も行っています。
  - Tailwind CSSは**インライン化済み（CDN不要）**のため、回線が不安定でも表示が崩れません。

## 🛠️ 使用技術

- **フロントエンド**: HTML5 / JavaScript (Vanilla JS) / Tailwind CSS（コンパイル済みCSSをインライン同梱）
- **配信形式**: 単一ファイルSPA（ビルド不要、ブラウザで開くだけで即起動）
- **利用API**:
  - [P2P地震情報 JSON API v2](https://www.p2pquake.net/)（気象庁電文）
    - WebSocket: `wss://api.p2pquake.net/v2/ws`（リアルタイム配信）
    - REST: `https://api.p2pquake.net/v2/history`（起動時・再接続時の欠損補完）
    - 電文コード: 551（地震）／552（津波警報・注意報）／554（EEW検知）／555（P2Pピア数）／556（EEW警報）／561・9611（ユーザー体感報告）
  - [WebNTP API](https://webntp.shogo82148.com/) / TimeAPI（日本標準時同期）
  - Web Speech API（ブラウザ標準 音声合成）
  - Web Audio API（アラート音）／Wake Lock API（画面常時ON）／Fullscreen API（全画面表示）

## 🚀 使い方

1. `sonaeru_live_v5.html` をダウンロードします。
2. お好みのブラウザ（Google Chrome, Safari, Edgeなど）でファイルを開くだけで動作します。
3. 画面上部のセレクトは「**WS自動（推奨）**」のままでOK。地震や津波が発生すると、気象庁が発表した電文をもとに自動で表示されます（発表からの反映は通常1秒以内）。平常時は画面が変化しませんが、これはWSが「地震発生時のみ」に電文を配信する仕様のためです（モニターバーにWS接続状態と最終受信時刻を常時表示しているので、監視の生死はそこで確認できます）。60秒おきのフェイルセーフ照合も内蔵しています。
   - 万が一環境がWSを遮断する場合は自動で「HTTP 監視中（15秒ポーリング）」に切り替わり、5分おきにWS復旧を自動確認します。
4. 常時表示モニターとして使う場合は、**⛶全画面**と**🔆常時ON**を有効化してください。
5. **🧪訓練**をONにすると、EEW／EEW取消／EEW予報／津波／地震のテスト電文を注入できます（EEWは画面には出ず、裏側のログ記録と551との相関処理のみ行い、詳細画面の「緊急地震速報」欄に受信済表示を反映します。実際の地震・津波情報ではありません。※訓練モードをOFFにすると消えます）。

## ⚖️ 免責事項

- 本サービスは個人開発による非公式の防災情報ポータルです。
- 緊急時や避難の判断には、自治体の防災無線、気象庁の公式発表、NHK等の公的報道機関の情報を最優先してください。
- 訓練モードで発報される電文はすべてテストデータであり、実際の地震・津波情報とは無関係です。

## 🔢 バージョン番号の規則

このアプリの版番号は **`v<メジャー>.<マイナー>`** の2段階で、**初版は `v1.0`** です。

```
v1.0 → v1.1 → … → v1.9 → v2.0 → v2.1 → … → v2.9 → v3.0 → …
        ↑ 2段目は 0〜9 の10個         ↑ .9 の次はメジャーを上げて .0 に戻る
```

- **`v1.0` が初公開**（アップデート履歴の先頭に「🎉 公開」と表示）
- 更新のたびに2段目を1つ進める（`v1.1`、`v1.2` …）
- **`.9` の次は必ず次のメジャーの `.0`**（`v1.9` → `v2.0`）。`.10` 以上は使いません
- 3段目（パッチ）は使いません

`regress.py` がこの規則を検査しています（違反すると FAIL）。

### v6.2 実測（2026/11/26 07:31 熊本県天草・芦北地方 M4.0 最大震度3）
| 時刻(JST) | 内容 | 経路 |
|---|---|---|
| 07:31:00 | 発生 | — |
| 07:32:12 | **緊急地震速報（予報）第5報** M3.7 最大震度3 | Wolfx API のみ（P2Pには553が無い） |
| 07:33:06 | 震度速報 VXSE51 | P2P登録 +2.2秒 |
| 07:34:29 | 震源情報 VXSE52 | P2P登録 +0.7秒 |
| 07:36:07 | 各地の震度 VXSE53 | P2P登録 +1.0秒 |

- P2PのWebSocket自体は高速（551の実測：発表07:55:47 → 着信07:55:48.49＝**1.5秒**）。遅さの主因はP2Pの配送ではなく、**予報（553）がP2Pに存在しないこと**と、P2Pの地震情報登録が気象庁発表から数十秒〜数分後になること。
- 気象庁XMLフィード（`feed/eqvol.xml`）には VXSE51/52/53 が載り、CORSは `*`。ただし気象庁側のキャッシュが60秒のため、実質の反映は発表から最大60秒。
- `feed/extra.xml` は気象警報・注意報専用（249件すべて警報系）で**緊急地震速報は載らない**。EEWのXML直URL（VXSE43/45）も404。

### v6.2 実データ検証（2026/11/27 00:11 石川県能登地方 M4.1 最大予測震度4）
| 時刻(JST) | 内容 | 経路 |
|---|---|---|
| 00:11:09 | 発生 | — |
| 00:11:44 | **緊急地震速報（予報）第7報** M4.1 深さ10km 最大予測震度4（最終報） | Wolfx API |
| 00:14:21 | 震源・震度情報 VXSE53（M3.8・深さ10km・最大震度2・観測5市区町村） | 気象庁XML／P2P同時刻 |

- v6.2のパーサに実電文を通した結果、**深さが `10000km` になる不具合を発見・修正**。気象庁XMLの `Coordinate` の第3要素はメートル単位（`+37.5+137.3+10000/` ＝ 10km）でした。

### 緊急地震速報の片付け（v6.2 追加）
| 状態 | 表示 |
|---|---|
| 予報・警報の発表直後 | 帯（琥珀＝予報／赤＝警報）＋モニターバーに「予報 石川県能登地方 最大震度4（最終報）」 |
| 同じ地震の地震情報（551）が到着 | 帯に「▸ 地震情報が届きました（まもなく片付けます・残り2分58秒）」を毎秒更新で表示 |
| **到着から3分後** | 帯が消え、バッジは「片付け済」（10分間）→「なし」 |
| 地震情報が届かない発表 | 片付けない（最大30分で「なし」＝従来どおり） |
| 片付けた後に新しい発表 | 通常どおり帯が出る（前の片付け状態は引き継がない） |

- 猶予は `eewClearDelayMs`（既定 3分）。**起点は「地震情報が入った時刻」**（速報の発表時刻ではありません）。地震情報との照合は震源地名または発生時刻（±3分）で行います。
- 地震情報が先に届いていて、あとから速報を受信した場合も、受信した時点から3分で片付けます（起点が無くて消えない、という抜けを作らないため）。
- 実時間計測：地震情報の到着 → 60秒後（残り2分00秒）→ 120秒後（残り58秒）→ **180秒で帯が消えて「片付け済」**。
- **画面を開いた時点で既に古い速報は出さない**：起動時や気象庁の発表一覧からの復元では「いつ地震情報が入ったか」が分からないため、地震情報の**発表時刻**を起点に3分を判定します。3分以上経っていればバッジは「なし」のまま（ログに「地震情報が届いてから3分以上経過しているため表示しません」）。
  - 20分前・10分前の地震 → 表示されない／1分前の地震 → 残り2分からカウントダウン、を実測で確認。

## 🗂 データ検証のしくみ（v6.2）

各地の観測震度（市町村・区別一覧）は、**気象庁の震度データベース**を唯一の正として生成しています。

### データの流れ

```
気象庁 震度DB API
  ├─ station.json        観測点マスタ（7,271点）
  ├─ city_by_code.json   市区町村マスタ（1,847件）
  └─ jma_points*.json    地震ごとの観測震度（49件分）
        ↓  data/build_yahoo.py
  sonaeru_live_v5.html   の pts（各地の観測震度）
```

### 地名の表記規則（Yahoo!天気準拠）

| 規則 | 例 |
|---|---|
| 都道府県は別カラムなので市区町村名のみ | — |
| 政令市の区は区名のみ | `札幌中央区北２条` → `中央区` |
| 北海道は振興局名を落とす | `十勝大樹町` → `大樹町` |
| 観測点名の末尾の町名を落とす | `石狩市花川` → `石狩市` |

### 震度キー（`SCALE_MAP` と一致必須）

| キー | 70 | 60 | 55 | 50 | 45 | 40 | 30 | 20 | 10 |
|---|---|---|---|---|---|---|---|---|---|
| 震度 | 7 | 6強 | 6弱 | 5強 | 5弱 | 4 | 3 | 2 | 1 |

> ⚠️ 震度のキーは **2か所** にあります。両方を揃えないと「不明」と表示されます。
> - `pts` のキー → 各地の観測震度の表
> - レコード本体の `max:` → 一覧・詳細画面の最大震度
>
> v5.2.10 では両方がズレて「震度6強」が「不明」になりました。`regress.py` が整合性を検査します。

### メンテナンス

```bash
# データを再生成（冪等・何度実行しても同じ結果）
python3 data/build_yahoo.py

# 回帰テスト（108項目）
python3 regress.py

# 描画確認（要: python3 -m http.server 8080）
python3 data/design_check.py h-2024-noto
```
