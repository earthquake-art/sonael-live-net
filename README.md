\# 🌐 防災情報ポータル - ソナエール・ライブ (v4.3)



気象庁発表の地震・津波データをリアルタイムに取得・可視化する、単一ファイル構成の防災情報Webアプリケーションです。


\---


## 🌐 公開サイト（今すぐブラウザで使う）
👉 [ソナエール・ライブ Web版はこちら](https://sites.google.com/view/sonael-live-net/)


\## 📌 主な機能



\- \*\*📡 リアルタイム地震情報\*\*

&#x20; - 「P2P地震情報 API v2」と連携し、最新の地震データを最短1秒〜60秒間隔で自動フェッチ。

\- \*\*⏱️ 日本標準時（JST）自動補正エンジン\*\*

&#x20; - デバイス（PC・スマホ）の内蔵時計が狂っていても、外部の高精度WebNTPサーバーと1分おきに自動同期して正確な日本時間をキープ。

\- \*\*🔄 電文合体（マージ）引き継ぎロジック\*\*

&#x20; - 第1報「震度速報」の震度データを、直後に届く第2報「震源に関する情報」へ自動引き継ぎ。震源決定直後に震度が「不明」に戻る現象を防止。

\- \*\*🌊 正確な津波情報判定\*\*

&#x20; - 津波の有無だけでなく、「若干の海面変動あり（被害なし）」や注意報・警報を正確に色分け表示。

\- \*\*🏛️ 過去の大地震アーカイブ（全30件）\*\*

&#x20; - 東日本大震災、阪神・淡路大震災、熊本地震、能登半島地震などの観測データを市区町村単位で収録。オフラインでも振り返り可能。

\- \*\*🔊 音声読み上げ（アクセシビリティ）\*\*

&#x20; - Web Speech API を活用し、画面を見られない緊急時でも合成音声で地震情報を確認可能。

\- \*\*📱 レスポンシブ＆ダークモードUI\*\*

&#x20; - Tailwind CSS を活用し、PCでは詳細・リストの2カラム、スマホではボトムナビゲーションによる快適な操作性を実現。



\---



\## 🛠️ 使用技術



\- \*\*フロントエンド\*\*: HTML5 / JavaScript (Vanilla JS) / Tailwind CSS (CDN)

\- \*\*配信形式\*\*: 単一ファイルSPA（ビルド不要、ブラウザで開くだけで即起動）

\- \*\*利用API\*\*:

&#x20; - \[P2P地震情報 JSON API v2](https://www.p2pquake.net/)（気象庁電文）

&#x20; - \[WebNTP API](https://webntp.shogo82148.com/) / TimeAPI（日本標準時同期）

&#x20; - Web Speech API（ブラウザ標準 音声合成）



\---



\## 🚀 使い方



1\. このリポジトリの `index.html` をダウンロードします。

2\. お好みのブラウザ（Google Chrome, Safari, Edgeなど）でファイルを開くだけで動作します。
