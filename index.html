📡 第1章 情報取得元および技術配信仕様

本ポータル「ソナエール・ライブ」は、防災啓発・情報支援を目的として開発された非公式の地震情報ビューアーです。

  • API配信基盤：気象庁が発表する防災気象情報（地震・津波に関する電文）を、「P2P地震情報 JSON API v2（p2pquake.net / 開発: たくや氏）」経由で取得し表示しています。地震（code 551）、津波警報・注意報・予報（code 552）、緊急地震速報・検知（code 554 / 556）、P2P参加ピア数（code 555）、ユーザー体感報告（code 561 / 9611）の各電文に対応しています。
  • WebSocketリアルタイム配信：主たる取得経路は、WebSocket（wss://api.p2pquake.net/v2/ws）への常時接続です。地震・津波・緊急地震速報が発表されると、サーバーから電文が即時にプッシュ配信され、画面へ反映されます（平常時に電文が流れないのは、このプッシュ方式の仕様です）。なお、地震発生から気象庁の発表までは、緊急地震速報（警報）でも数秒〜十数秒、震度速報は約1分、震源に関する情報・各地の震度に関する情報は約1〜5分かかるため、発生から画面反映まではこの発表時間がそのままかかります（かつて本アプリが表記していた「最速約0.1秒」は誤りでした）。
  • 自動再接続・フォールバック：切断時は指数バックオフで自動的に再接続し、再接続のたびに、またタブへ戻った際に、HTTP「/v2/history」で最新状態を自動補完します。さらにWS監視中も60秒ごとにHTTPで照合するフェイルセーフを備えています（v5.0.9〜）。ネットワーク環境によりWebSocketが接続できない場合は、HTTPポーリング（15秒／30秒／60秒）へ自動的に切り替わり、5分ごとにWS復旧を自動確認します。
  • 緊急地震速報（予報・警報）の裏側処理：緊急地震速報は、画面上のパネル表示・専用アラート音・自動読上げは行いません。受信した電文はモニターバーのログへ静かに記録した上で、551（震度速報・震源情報）と発生時刻±90秒で自動相関し、該当する地震の詳細画面の「緊急地震速報」欄に、実際に発表された内容どおりに記載します（警報・code 556 →「【警報】（受信済・第N報）」、警報の取消 →「【警報】（発表後取消）」、予報の検知・code 554 →「【予報】（受信済）」）。EEWを受信したにもかかわらず観測された最大震度が震度3以下だった場合は、「緊急地震速報【予報】／【警報】」とだけ記載します。第N報の続報更新の検知（いずれも画面遷移・音声を伴わない裏側処理です）にも対応します。
  • 津波モニター（code 552）：大津波警報・津波警報・津波注意報の区分、対象沿岸、予想される高さ（巨大／高い／１０ｍ超など）、第1波到達予想（arrivalTime／「ただちに津波来襲と予測」等のcondition）、即時避難の呼びかけ、解除を表示します。地震詳細の津波情報は、気象庁電文中の domesticTsunami 等に基づく参考表示です。
  • 参考表示について：モニターバーに表示される「P2Pピア数」と「ユーザー体感報告（561 / 9611）」は、P2Pネットワークの状態とユーザーの体感の集計に基づく参考値であり、気象庁その他の公的機関による発表ではありません。
  • 訓練モードについて：🧪「訓練」をONにした場合に発報される緊急地震速報・津波・地震の電文は、すべて動作確認用のテストデータであり、実際の気象庁電文ではありません（「訓練」バッジ付きで表示されます）。
  • 震度の集約とソート：各都道府県内の市区町村について、同一の自治体内に複数の観測点が存在し異なる震度が観測された場合は、最も強い「最大震度」にのみ集約表示します。また、表示順序は気象庁の公表基準に準拠し、都道府県は北から南（JISコード順）、市区町村は五十音順に自動整列しています。
  • 発生時刻の正確な表示：すべての日時は日本標準時（JST / UTC+9）として厳密に解釈・表示され、閲覧端末のタイムゾーン設定には依存しません。気象庁の公式発表（分単位）に準拠しつつ、最新地震と過去アーカイブでそれぞれ最適なフォーマット（秒単位・または「○○ごろ」）を用いて正確な時系列を把握できるようにしています。
  • 時計の自動補正：端末（PC・スマホ）の内蔵時計のずれは、外部の高精度WebNTPサーバー等と1分おきに自動同期して補正します（補正状況はヘッダーの「JST同期済」バッジで確認できます）。

⚠️ 第2章 防災行動ガイドライン（命を守るための原則）

【最重要原則：画面を見るよりも直ちに身の安全を確保】 強い揺れを感じたとき、または緊急地震速報を受信した際は、スマートフォンやPC画面の確認よりも、直ちに身の安全を確保する行動を最優先してください。
  • シェイクアウト姿勢の徹底：強い揺れを感じた場合は「まず低く」「頭を守り」「動かない」の3原則を守り、丈夫な机の下などに避難してください。倒壊の恐れがある家具やガラス窓から離れてください。
  • 津波からの避難：津波警報・津波注意報が発表された場合、または強い揺れや長くゆっくりとした揺れを感じた場合は、沿岸部や河口付近から直ちに離れ、可能な限り高い場所（高台や津波避難ビル・タワー）へ避難してください。警報や注意報が解除されるまで絶対に海や川に近づかないでください。
  • 火災や二次災害の防止：避難する際は、火の元を確認し、可能であればブレーカーを落としてから避難してください（通電火災の防止）。

本サービスをご利用になるすべてのユーザーは、以下の規約および免責事項に同意したものとみなします。

  • 非公式サービスの明示：当サイトは個人開発による非公式の防災情報ポータルであり、気象業務法に基づく予報業務許可事業者ではありません。独自の地震予知、予報、警報の発令等は一切行いません。
  • 即時性・正確性の非保証：インターネット回線の混雑状況、利用端末の処理能力、またはAPIサーバーの一時的な障害により、情報の表示に遅延、欠落、または不整合が生じる場合があります。また、ネットワーク環境によりWebSocket接続が拒否される場合、情報はHTTPポーリング経路で表示されるため即時性が低下します。速報値は気象庁による後日の精査により改定されることがあります。
  • 参考表示およびデモ表示：ユーザー体感報告・P2Pピア数などは参考値であり、確定情報ではありません。また、訓練モードで発報される電文はすべてテストデータであり、実際の気象庁発表情報ではありません。これらを実際の防災判断の根拠として扱わないでください。
  • 音声読上げ・アラート音：「🔊音声読上」ボタンおよび津波警報受信時のWeb Audioアラート音は、端末やブラウザの仕様、音量設定、OSのサイレント設定等により再生されない場合があります。緊急地震速報（警報）受信時は音声・アラートは一切発報されません。音の有無にかかわらず、必ず画面の表示内容を目視で確認してください。
  • 責任の免除：本サイトの利用によって生じた直接的、間接的を問わずいかなる損害（生命、身体、財産に対する損害を含む）についても、開発者およびAPI情報提供者は一切の責任を負わないものとします。
  • 禁止事項：クローラー等を用いた過度な連続アクセスによるサーバーへの負荷行為、本サイトのデータを改ざん・悪用する行為、虚偽の災害情報を流布する行為を固く禁じます。
  • 公的情報の優先：災害時における避難行動や最終的な安全確認の判断においては、必ずお住まいの自治体による防災行政無線、気象庁の公式サイト、およびNHK等の公的報道機関の情報を最優先してください。
