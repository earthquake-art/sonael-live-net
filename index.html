📡 第1章 情報取得元および技術配信仕様

本ポータル「ソナエール・ライブ」は、防災啓発・情報支援を目的として開発された非公式の地震情報ビューアーです。

  • API配信基盤：気象庁が発表する防災気象情報（地震・津波に関する電文）を、「P2P地震情報 JSON API（p2pquake.net API v2 / 開発: たくや氏）」経由でリアルタイム自動取得し表示しています。
  • リアルタイム同期フェッチ：ネットワーク負荷の軽減と即時性の両立を図るため、ブラウザ内の時計と完全に同期し、設定された秒数（00秒、15秒、30秒、45秒等）の瞬間にAPIへリクエストを発行する独自の軽量通信エンジンを搭載しています。
  • 震度の集約とソート：各都道府県内の市区町村について、同一の自治体内に複数の観測点が存在し異なる震度が観測された場合は、最も強い「最大震度」にのみ集約表示します。また、表示順序は気象庁の公表基準に準拠し、都道府県は北から南（JISコード順）、市区町村は五十音順に自動整列しています。
  • 発生時刻の正確な表示：気象庁の公式発表（分単位）に準拠しつつ、最新地震と過去アーカイブでそれぞれ最適なフォーマット（秒単位・または「○○ごろ」）を用いて正確な時系列を把握できるようにしています。

⚠️ 第2章 防災行動ガイドライン（命を守るための原則）

【最重要原則：画面を見るよりも直ちに身の安全を確保】 強い揺れを感じたとき、または緊急地震速報を受信した際は、スマートフォンやPC画面の確認よりも、直ちに身の安全を確保する行動を最優先してください。
  • シェイクアウト姿勢の徹底：強い揺れを感じた場合は「まず低く」「頭を守り」「動かない」の3原則を守り、丈夫な机の下などに避難してください。倒壊の恐れがある家具やガラス窓から離れてください。
  • 津波からの避難：津波警報・津波注意報が発表された場合、または強い揺れや長くゆっくりとした揺れを感じた場合は、沿岸部や河口付近から直ちに離れ、可能な限り高い場所（高台や津波避難ビル・タワー）へ避難してください。警報や注意報が解除されるまで絶対に海や川に近づかないでください。
  • 火災や二次災害の防止：避難する際は、火の元を確認し、可能であればブレーカーを落としてから避難してください（通電火災の防止）。
