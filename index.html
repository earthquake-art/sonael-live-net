📡 1. 情報取得元および技術仕様

  • 最新地震データ： 気象庁が発表する電文に基づき、「P2P地震情報 JSON API（p2pquake.net API v2 / code:551 地震情報）」より自動取得しています。
  • 遠地地震の自動判別： 海外等で発生した遠地地震（国内で強い揺れが予想されない地震）を自動検知し、緊急地震速報の誤判定を防止して「遠地地震」と明記します。
  • リスト切り替え機能： 最新のリアルタイム地震（30件）と、過去の歴史的大地震アーカイブを独立したタブでいつでも切り替えて閲覧可能です。
  • 新着地震の自動表示： 閲覧中に新しい地震が発生した際は、自動的に「最新地震」タブに切り替わり、最新情報が表示されます。
  • 数値の自動精査・更新機能： 地震発生直後の速報値から、気象庁が後から詳細な深さ・マグニチュードを再計算（精査）した場合、15秒ごとの自動通信により自動で最新の詳細値に書き換わります。
  • 緊急地震速報の区分判定： 気象庁の発表基準に基づき、最大予測震度5弱以上を「緊急地震速報【警報】」、最大予測震度3以上またはM3.5以上を「緊急地震速報【予報】」として表示・判定しています。
  • 過去地震アーカイブ： 気象庁「震度データベース検索」および公式報告資料に基づき独自編纂しています。
  • 観測震度の表示基準： 気象庁および報道機関（NHK等）の公表基準に準拠し、各市区町村内で観測された【最大震度】の階級に集約・表示しています。

⚠️ 2. 防災行動ガイドライン（命を守るための原則）

【最重要】強い揺れを感じた際や緊急地震速報を受信した際は、本画面の閲覧よりも直ちに身の安全の確保を最優先してください。

  • 屋内： 頭部を保護し、丈夫な机の下に身を隠すなど落下物から身を守ってください。
  • 沿岸部・河口付近： 津波警報・注意報が発表された場合、また揺れが小さくても長くゆっくりした揺れを感じた場合は、直ちに海から離れ、高台や頑丈な津波避難ビルへ避難してください。

⚖️ 3. 利用規約および免責事項

  • 当サイトは個人開発による非公式の防災啓発・情報支援ポータルです。気象業務法に基づく予報業務許可事業者ではありません。
  • インターネット回線の混雑、APIサーバーの一時的な障害、端末の通信状態等により、情報の遅延や欠落、表示の不整合が生じる場合があります。
